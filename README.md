# Jianjun Ma — Academic portfolio

English-first portfolio with an optional Chinese toggle. Static HTML, CSS and JavaScript; no build step or external dependencies. Open index.html to preview.

## Design

Editorial typography, a compact top navigation, a portrait-led introduction, readable research sections and a seven-frame photo journal. Mobile navigation, keyboard-accessible image viewer and reduced-motion support are included.

## Photos

Seven views use six original photographs: three existing photos, the night scene in its full composition, the desk image with its black borders hidden, and two separate classroom frames. Cropping is non-destructive CSS framing, shared by gallery and lightbox. Original files retain their pixels; no stories, dates or locations are invented.

## Content

Profile and ACM publication details follow the owner’s confirmed information. Other work carries no unverified submission or ranking labels. No private phone number or unnecessary sensitive profile data is displayed.

## Files

- index.html: paired English and Chinese content, metadata and image frames.
- css/style.css: responsive design and image framing.
- js/script.js: language preference, navigation and lightbox.
- images/: local assets.
