无人机自然语言多约束目标检索 Benchmark A benchmark for natural-language multi-constraint target retrieval in UAV imagery

围绕自然语言查询中的多重条件，构建无人机影像目标检索数据与评测任务。研究组织采用五约束设定与 T1–T6 任务体系。 This project develops data and evaluation tasks for retrieving targets in UAV imagery under multiple natural-language conditions. The study is organized around a five-constraint setting and a T1–T6 task taxonomy.

精选项目 Selected Projects

无人机管网巡检 UAV pipeline inspection

围绕无人机巡检影像，开展数据集构建、目标检测与场景感知评估，关注实际巡检条件下的模型表现。 Dataset construction, object detection, and scene-aware evaluation for UAV inspection imagery, with attention to model performance under real inspection conditions.

医学影像与互信息 Medical imaging and mutual information

使用信息论方法分析医学影像特征间的信息关联，探索肿瘤数据的定量描述。相关论文见学术论文栏目。 Information-theoretic analysis of relationships among medical image features, exploring quantitative descriptions of tumor data. See Publications for the related paper.

光伏预测 Photovoltaic forecasting

面向光伏预测的时间序列建模与预测研究。 Time-series modeling and forecasting research for photovoltaic applications.

无人机与机库智慧巡检 UAV and dock-based smart inspection

结合 CLIP 场景分选、YOLO 预标注与 SAM 掩码提取，探索半自动标注流程。 Exploring a semi-automatic annotation workflow combining CLIP scene classification, YOLO pre-annotations, and SAM mask extraction.

更多实践：应用开发与数据分析 More practice: application development and data analysis

英语人 APP English-learning app

HarmonyOS 手机与手表协同英语学习应用，结合遗忘曲线与 AI 批改。 A HarmonyOS English-learning application for phones and watches, combining a forgetting-curve approach with AI-assisted feedback.

智能图像处理工作站 Image-processing workstation

使用 Python、PyQt5 与 OpenCV，开展图像处理和模式识别实践。 Image processing and pattern recognition practice using Python, PyQt5, and OpenCV.

家庭能源消费短期预测 Short-term household energy forecasting

对比深度学习时间序列模型，并探索预测不确定性的量化。 Comparing deep-learning time-series models and exploring predictive uncertainty quantification.

农作物产量与产值预测 Crop yield and output-value forecasting

基于 FAO 多源农业数据，开展缺失值处理、多模型对比与集成预测。 Missing-data handling, model comparisons, and ensemble forecasting using multi-source FAO agricultural data.
